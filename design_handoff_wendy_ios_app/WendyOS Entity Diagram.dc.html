RULES
One home, one live location. An asset belongs to one place and can be seen anywhere it currently is.
Robot = body + devices. Joints, power, safety and simulation exist only on robots; a device is compute with peripherals.
Any asset can run a mission. A camera device can run detect + goal steps; *route steps need a robot.
Chat can act on everything. It answers questions, configures devices, places and fleets, and runs missions. Answers are instant; anything that moves a robot or changes config waits for a tap. Tap Action to see its reach.
Fleets aren’t places. They group assets for bulk updates and missions.
Data has no home. It’s tagged with the asset, place and run that produced it.
