Budget estimates sum to $6.85. OpenAI estimates use the higher long-context standard rates captured from [OpenAI pricing](https://developers.openai.com/api/docs/pricing). Claude reports a client estimate. These dollar values are for budget tracking and are not comparable invoices or subscription charges. The total token column includes cached input once and includes output once.

The task was to deploy a supplied HTTP app with Wendy to the named target, leave it running, and verify its health response. Every attempt used a fresh workspace, unique app ID, and nonce. The grader checked two HTTP responses inside the exact container through the selected transport, running state, and the prior versions and states of unrelated apps. All six cleanup checks passed.

The targets were a dedicated generic WendyOS ARM64 VM and an AGX Orin reached through an explicit cloud selector. Both ran WendyOS 0.19.4. The VM agent reported 2026.09.26-062348; the Orin agent reported dev. Deterministic fixture checks warmed build and image caches before measurement.

The configured clients were Codex CLI 0.157.1 with gpt-6-astra and xhigh effort, Claude Code 2.1.272 with claude-opus-4-8 and medium effort, and the candidate Wendy CLI with gpt-6-astra and its saved 4096-token response limit. Wendy used its API defaults for reasoning. These are configured product experiences, with different instructions and reasoning settings. They do not isolate the effect of Wendy integration from model or client behavior.

The candidate was based on `7d8bf9eeec6fcc9100df3e99c10f5dc4f4b2b33d` with the uncommitted token-accounting changes. The local experiment directory `results/20260927-080118-6906cd/` retains the binary and script hashes, source copies, full configuration, prompts, event logs, verifier evidence, and per-attempt results. The supplied CLI path was explicit in each initial prompt, so login-shell PATH settings could not select an older installed binary.

An earlier calibration experiment is excluded. Its grader required a host-shell operation absent on the initial simulator agent, and a Codex login shell selected the older installed CLI. The calibration was stopped, its apps were cleaned up, and the benchmark was corrected before this pilot. The completed calibration attempt had a $0.68 conservative estimate; the interrupted Codex attempt did not report final usage, so its cost is unknown. The replacement pilot used an $80 soft budget after reserving $20 of the original approximate $100 allowance for calibration.

The full suite also defines simulator creation, startup-fault repair, app update, and app shutdown. Those tasks are separate from the six measured deployment attempts above. See [the benchmark README](README.md) for execution, grading, and measurement rules.
