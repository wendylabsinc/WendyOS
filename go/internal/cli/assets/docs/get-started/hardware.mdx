For Linux, WendyOS, and Mac targets, verify the connection from your development machine:

```bash
wendy discover
wendy device info --device <name-or-address>
```

Then deploy with `wendy run`. If discovery fails, see [connection troubleshooting](/docs/errors#target-not-found). After your first deployment, use [debugging tools](/docs/remote-debugging/vscode-extension) to inspect the app.
