---
title: Connect Wendy to ChatGPT
description: Use the hosted Wendy plugin in ChatGPT with your devices through a Wendy CLI session on your computer.
---

The Wendy plugin for ChatGPT connects to the Wendy Cloud relay. The relay
forwards ChatGPT's tool calls to a signed-in Wendy CLI running on your
computer, so the same plugin works in ChatGPT on the web, desktop, and mobile.

## Start the CLI session

Install the [Wendy CLI](/docs/#1-install-the-wendy-cli), sign in to Wendy Cloud,
and start the relay in an interactive terminal:

```sh
wendy auth login
wendy cloud mcp --allow-read --allow-tool device_connect
```

Keep the computer awake and the command running. Calls stop when the CLI exits,
including calls from your phone. Your organization must allow MCP and Hosted
MCP, and the CLI must support the relay's current tool catalog.

## Connect the plugin

1. **Add the Wendy plugin in ChatGPT** and sign in with the same Wendy account
   and organization as the CLI.
2. **Ask ChatGPT to check Wendy's status.** The first tool call starts pairing.
3. **Compare the code** shown by ChatGPT with the code in the terminal, accept
   it, and retry the status check.

Start with: "Show my Wendy Cloud devices."

For automatic pairing with ChatGPT's known OAuth client, add `--auto-accept`.
It applies to session pairing only and does not change tool permissions or
per-call confirmations. Other clients still use manual pairing.

## Permissions

Built-in read-only device and Cloud tools that do not access the host are
available by default, with terminal confirmation before each call. The command
above uses `--allow-read` to skip confirmation for those reads. It also permits
`device_connect`, which still asks for confirmation. Add specific permissions
for a requested task, such as `camera_snapshot` for a still image or
`container_stop` for stopping an app. A camera snapshot requires GStreamer on
the CLI computer. Local discovery through `device_list` also requires explicit
permission and confirmation. Read-only annotations on host or proxied tools do
not qualify for `--allow-read`.

`--allow-all` permits every supported relay tool and skips every per-call
confirmation, including device changes and host access. Pairing is still
separate and uses the matching-code prompt unless `--auto-accept` applies.

## Work with Wendy Data

Wendy's data skill covers [campaigns, recordings, and app-provided data](/docs/data).
For example, ask:

> Help me record device health around a machine fault with a Wendy Data campaign.

General campaign and episode management uses `wendy data` commands through a
local terminal. Without terminal access, the assistant can prepare a campaign
and operator commands. After deploying, inspect a completed episode to check
which sources recorded.

## If Wendy does not respond

- Check that `wendy cloud mcp` is still running and signed in to the same
  account and organization as the plugin.
- Update the Wendy CLI if the relay reports an incompatible tool catalog.
- After updating Wendy, refresh the plugin's tools and start a new conversation
  so ChatGPT loads the current tool catalog.

The ChatGPT desktop local plugin (`wendy mcp setup chatgpt`, `wendy mcp gateway`)
has been removed. Use the hosted plugin above. For Claude Code, Cursor, and other
local MCP clients, `wendy mcp setup` still configures `wendy mcp serve`.

See [OpenAI's plugin installation guide](https://learn.chatgpt.com/docs/plugins)
for the Plugins Directory interface.
