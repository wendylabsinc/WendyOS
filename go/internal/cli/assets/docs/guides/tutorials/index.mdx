Choose a language to create and deploy a small application. Start with an
[installed CLI and connected device](/docs/#1-install-the-wendy-cli), or use a
[virtual device](/docs/installation/wendyos-virtual-machine).

| Language | Start here |
| --- | --- |
| Python | [Build a Python app](/docs/guides/tutorials/python/hello-world) |
| Swift | [Build a Swift app](/docs/guides/tutorials/swift/hello-world) |
| C++ | [Build a C++ app](/docs/guides/tutorials/cpp/hello-world) |
| Rust | [Build a Rust app](/docs/guides/tutorials/rust/hello-world) |
| TypeScript | [Build a TypeScript app](/docs/guides/tutorials/typescript/hello-world) |
| Mojo | [Build a Mojo app](/docs/guides/tutorials/mojo/hello-world) |

After your first deployment, use the language's other tutorials for web services,
hardware access, and application integrations. To connect services on several
Wendy devices, follow [Wendy Net service sharing](/docs/guides/wendy-net-services).
