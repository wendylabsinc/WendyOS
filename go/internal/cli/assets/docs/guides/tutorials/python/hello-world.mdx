Deploy a small HTTP server, check its response, then change the response and
redeploy. This is the starting project for [adding an API endpoint](/docs/guides/tutorials/python/simple-web-server).

## Prerequisites

- [Wendy CLI installed](/docs/installation/cli) on your development computer.
- Docker running with Buildx. Check with `docker info` and `docker buildx version`.
- A [Linux device or WendyOS VM](/docs/installation) ready to run your app.

Python and dependencies run inside the container. You do not need Python
installed on your development computer. Use the VM setup guide if you do not
have hardware; this tutorial also works with an existing Linux machine running
Wendy Agent.

## 1. Create the project

```bash
wendy init hello-world --target wendyos --language python --template simple-api --var APP_ID=hello-world --var PORT=3001 --assistant skip --git-init no
cd hello-world
```

The template creates `app.py`, `Dockerfile`, and `wendy.json`. The application
uses FastAPI; the Dockerfile installs its dependencies and starts it with
Uvicorn. [`wendy.json`](/docs/reference/app-configuration) declares network
access, a readiness check on port 3001, and a hook to open the browser.

## 2. Deploy and check the response

```bash
wendy run
```

Select your target. Wendy builds and deploys the server, checks readiness, and
opens its URL. Open the address printed by Wendy if the browser does not open.
The root page should return:

```json
{"message":"hello-world"}
```

Use the printed address, including its port. A local VM normally uses a
forwarded address on your development computer; a physical device uses its own
address. If the build, connection, or readiness check fails, use
[first-deployment troubleshooting](/docs/errors).

## 3. Change the response

In `app.py`, find the function decorated with `@app.get("/")`. Change its return
value to:

```python
return {"message": "Hello from my device"}
```

Stop the attached CLI with Ctrl+C, then start the watch loop:

```bash
wendy run --watch
```

Refresh the browser and check for the new message. Further edits trigger a
rebuild and deployment when you save. This verifies that your source change
reached the target.

## Finish or continue

Ctrl+C ends the attached CLI session. To stop the deployed app, run:

```bash
wendy device apps stop hello-world
```

If you used a VM and are finished with it, find its name with `wendy vm list`
and stop it with `wendy vm stop <name>`.

Keep this project for the next tutorial: [add an endpoint that validates input
and calculates a result](/docs/guides/tutorials/python/simple-web-server).
