---
title: Build a web server
description: Deploy a TypeScript HTTP server to a Wendy target and verify its response.
language: typescript
---

You need the [Wendy CLI](/docs/installation/developer-machine-setup), a running container builder, and a Linux/WendyOS target or [simulator](/docs/installation/wendyos-virtual-machine). The [quickstart](/docs/) covers those prerequisites. Node.js is only needed locally if you also want to run the app outside Wendy.

## 1. Create it

```bash
wendy init simple-server --target wendyos --language node --template simple-api --var APP_ID=simple-server --var PORT=3000 --assistant skip --git-init no
cd simple-server
```

## 2. Run it

```bash
wendy run
```

Select your target. Wendy builds the image, deploys it, and streams logs. After readiness succeeds, expect a line like this, with your target's address:

```text
App reachable at http://192.168.123.222:3000
```

A simulator using default networking prints `http://127.0.0.1:3000` instead.

## 3. Open it

Open the printed URL in your browser. You should see:

```json
{"message":"hello-world"}
```

Your web service is running on the target. Edit `src/index.ts` to change the response, then use `wendy run --watch` to redeploy as you edit.

[Understand what Wendy generated](/docs/guides/tutorials/typescript/generated-server), including the Dockerfile and `wendy.json`, or use [troubleshooting](/docs/errors) if you did not get a response.
