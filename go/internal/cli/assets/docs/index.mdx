Wendy is a full-stack platform that offers an operating system for NVIDIA Jetson, AGX Orin, Thor, Raspberry Pi, Qualcomm Dragonwing, and ESP32 systems, with app deployments, logging, crash reporting, AI inference, networking, simulations, vision, fleet management, and data integration.

## Install the Wendy CLI

The Wendy CLI is the gateway that you, or [coding agents](/docs/guides/llm-integration) like Claude Code and Codex, use to deploy to WendyOS devices.

```bash title="macOS and Linux"
curl -fsSL https://install.wendy.dev/cli.sh | bash
```

```powershell title="Windows"
winget install WendyLabs.Wendy --source winget
```

Run `wendy --version` to confirm. If the command is not found, open a new terminal.

To build apps on Windows, run the macOS and Linux command inside WSL2 instead.
