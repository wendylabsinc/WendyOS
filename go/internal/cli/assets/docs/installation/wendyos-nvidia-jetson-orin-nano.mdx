This page installs WendyOS on a **Jetson Orin Nano developer kit** over USB.
Current recovery releases install the boot firmware and OS together. An
NVMe-to-USB adapter is needed only for the separate rootfs-only workflow below.

<Callout title="Other Jetson boards">
  The same steps work for **AGX Orin developer kits**: choose `jetson-agx-orin` and select NVMe or eMMC.
  Custom robot carriers need their vendor's procedure. For Unitree G1 PC2, follow
  [Install Wendy Agent on Unitree G1](/docs/installation/wendy-agent-unitree-g1)
  and keep its vendor Ubuntu installation.
</Callout>

## Full USB recovery

You need the developer kit and power supply, an NVMe SSD installed in the Orin
Nano, a USB data cable, and a development machine with the current Wendy CLI
([install it](/docs/installation/cli)).
AGX Orin can use its onboard eMMC instead of NVMe.

Full recovery **erases QSPI and all partitions on the selected OS storage,
including `/data`**. Review that scope before you start.

1. Connect the computer to the Jetson's recovery USB-C port using a data cable.
   On AGX Orin, use the USB-C port next to the 40-pin header.

   <video width="100%" autoPlay loop muted playsInline>
     <source src="/videos/installation/jetson-mac-usb-cable.mp4" type="video/mp4" />
   </video>

2. On Orin Nano, disconnect power, bridge **FC REC** to **GND** (pins 9–10 on
   the button header under the module), then reconnect power. Remove the jumper
   after recovery mode is entered. Check the header labels for your board revision.
   On AGX Orin, hold Force Recovery, tap Reset/Power, then release Force Recovery.

   <video width="100%" autoPlay loop muted playsInline>
     <source src="/videos/installation/jetson-power-cable-insertion.mp4" type="video/mp4" />
   </video>

3. Run the installer and pick the Jetson it finds in recovery mode:

   ```sh
   wendy install
   ```

   The CLI downloads and verifies the image, asks for your password when it
   needs it, and shows flash progress.

   <CliShot flow="os-install" step="select-device-type" alt="The Wendy CLI prompting you to choose a device type before flashing WendyOS" />

4. Keep power and USB attached through final success. Follow the installer’s
   reboot or power-cycle instruction to leave recovery mode.

The installer also asks for a device name and Wi-Fi.

On macOS, the terminal may need Full Disk Access. `wendy` claims the flashing
disks so macOS neither mounts them nor asks about unreadable disks; if such a
prompt still appears, choose **Ignore**, not Initialize or Eject. On Windows, allow the
installer's required driver/elevation step and cancel any request to format the
newly attached raw disk. The installer reports these platform-specific steps.

## Rootfs-only SD/NVMe imaging

Use this when the Jetson already has boot firmware compatible with the selected
WendyOS release. This path **does not update QSPI**. Writing an image successfully
does not prove the existing firmware can boot it.

Connect the SSD with an NVMe-to-USB adapter, or an SD card reader for a supported
Orin Nano SD image:

<video width="100%" autoPlay loop muted playsInline>
  <source src="/videos/installation/jetson-nvme-mac-adapter.mp4" type="video/mp4" />
</video>


```sh
wendy install --rootfs-only
```

Pick **Jetson Orin Nano** and the drive, and check its size before confirming.
For AGX Orin, rootfs-only imaging supports NVMe; eMMC uses full recovery.

After writing and ejecting, insert the SSD/card in the Jetson and power it on.

</video>

## Verify first boot

Allow the board to boot, then discover it:

```sh
wendy discover
```

<CliShot flow="discover" step="devices" alt="The Wendy CLI listing discovered WendyOS devices on the network" />

Your Jetson appears under the device name you chose.

<Accordions>
  <Accordion title="Scripted installs and verification">
    Every prompt has a flag, so installs can run without a terminal. For example:

    ```sh
    wendy install --device-type jetson-orin-nano --device-name lab-orin --no-wifi --force
    ```

    Use `jetson-agx-orin` and `--storage nvme` or `--storage emmc` for AGX Orin.
    `wendy install plan` describes an installation as JSON without writing
    anything, and `wendy install verify` checks first boot at an explicit
    address. For a board on USB-C, pass the link-local address that
    `wendy discover` prints, such as `fe80::…%en31`. Coding agents use the same
    steps through MCP; see [agent-assisted setup](/docs/installation/agent-assisted-setup).
    All flags are in the [installation command reference](/docs/advanced/clients/wendy-cli/commands/os/install).
  </Accordion>
</Accordions>
