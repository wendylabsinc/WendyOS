## For coding agents

Retrieve the quickstart, your target's setup guide, app configuration, and the command reference for the operation you need. Check the target platform before choosing a template. Use explicit target and template flags in non-interactive sessions.

The site publishes `/llms.txt`, `/llms-full.txt`, `/reference/cli.json`, and `/reference/wendy.schema.json` under the current documentation version. Every page has a raw Markdown link and a copy action. These files are generated during the docs build from this revision's pages, CLI definitions, and app schema.

CLI JSON lists command paths, synopsis, aliases, and local and persistent options. To determine inherited flags, walk the command's parent paths. It describes command inputs, not a universal schema for command output.

For API and protocol definitions, use the [repository source](https://github.com/wendylabsinc/WendyOS). The docs do not assign error codes that the CLI has not implemented; [troubleshooting](/docs/errors) is indexed by symptoms and error text.
