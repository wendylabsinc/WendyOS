# Wendy engineering

Opt-in workflows for engineers modifying Wendy's CLI, agent, OS, and repository.
This group is separate from the end-user `wendy-agentic-coding` group and is not
installed by `wendy mcp setup` or `wendy init`.

The Codex and Claude manifests load `wendy-codebase` and `wendy-pr-workflow`.
Claude also has the repository orientation and PR commands and the runtime
debugger agent. Enable this group only in an engineering assistant setup.
